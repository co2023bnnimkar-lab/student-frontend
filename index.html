How it works

How RollCall works

Three separate pieces, each hosted on its own. If one needs a restart, the others carry on.

The three pieces

What you see, and what sits behind it

The page you are on talks to an API, and only the API talks to the database.

Open roster
01

The page you see

Hosted on Netlify

Plain HTML, CSS and JavaScript. It runs in your browser and asks the API for data.

Netlify

The API

Hosted on Render

Checks what you send, applies the rules, then reads or writes the database.

Render

The database

Hosted on MongoDB Atlas

Holds every student record. Reachable only through the API, never straight from the browser.

Endpoints

  • GET/api/studentsList the roster, optionally filtered with ?q=
  • GET/api/students/:idFetch one student by ID
  • POST/api/studentsAdd a student
  • PUT/api/students/:idChange a student's details
  • DELETE/api/students/:idRemove a student
